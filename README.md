# garage42-assets

Este repositorio contiene los assets públicos de Garage 42 para usar en el sitio web y en Odoo mediante URLs directas.

## Organización

Las imágenes y los videos de cada proyecto deben subirse dentro de la carpeta correspondiente en `proyectos/`.

## Recomendaciones para los archivos

- Usar preferentemente el formato `.webp` para imágenes.
- Evitar espacios, tildes y caracteres especiales en los nombres de archivo.
- Usar nombres simples y descriptivos, por ejemplo:

```text
portada.webp
01.webp
02.webp
03.webp
antes.webp
despues.webp
```

## URLs directas mediante GitHub Pages

GitHub Pages está configurado para publicar la rama `main` desde la carpeta `/ (root)`.

La URL directa de un archivo sigue este formato:

```text
https://kaliken69.github.io/garage42-assets/ruta/al/archivo.webp
```

Por ejemplo, para `proyectos/cayenne-955/portada.webp`:

```text
https://kaliken69.github.io/garage42-assets/proyectos/cayenne-955/portada.webp
```

Los nombres de archivo y de carpeta distinguen entre mayúsculas y minúsculas. Después de subir un archivo, GitHub Pages puede tardar unos minutos en publicarlo.
